## 강의실 & 교사 기준 시간표 뷰어

강의실과 교사 시점에서 시간표를 조회할 수 있습니다. 현재는 2학년 수업만 포함되어 있습니다.

### 사용법

`index.html`을 열고 우상단 불러오기 버튼을 통해 `timetable.json` 파일을 불러온 이후 강의실 / 교사를 선택하세요.

### 시간표 데이터를 추가하는 방법

리로스쿨 이동수업출석부 메뉴에서 **본인 학년 강좌**에 커서를 호버할 경우 다음 이미지처럼 과목명과 수업 시간, 담당 교사 및 강의실을 얻을 수 있습니다.

### 트리비아

JSON Schema는 100% AI Generated이며, `index.html` 또한 99% AI Generated 입니다. 추후에 시간이 나더라도 충분히 잘 작동하기에 수정할 의향은 별로 없습니다.
